# Sales Territory Planner

A single-file territory planning tool. No install, no account, no server — your
data stays in your browser.

## Get it

1. **[Download index.html](https://raw.githubusercontent.com/loganlemming/territory-planner-releases/main/index.html)**
   (right-click → Save Link As…)
2. Double-click the downloaded file to open it in your browser.
3. Bookmark it, or keep it somewhere you'll find it again.

## Updates

The planner checks this repo for new versions and shows a banner when one is
available. Click **Download**, then replace your old file with the new one.

Your saved plans normally carry over automatically. Before updating you can use
**Actions → Backup All Data** to save a copy, and **Actions → Restore Backup** to
bring it back if anything goes missing.

To check manually: **Actions → Check for Updates**.

See [CHANGELOG.md](CHANGELOG.md) for what's changed.
